# Octop 本地改造记录

作者：chenjixian

本目录记录当前工作区中 Octop 用户隔离、文件分享及相关 MCN 接入改动的背景、实现核心、兼容边界和核实证据。范围以整理时的 `git diff HEAD` 与未跟踪源码为准，不追溯 Git 历史，也不把已有代码都算作本次新增。

整理期间检测到工作区外部新增的启动修复、维护模式及诊断改动，已在变更范围中单独增补，并同步说明其影响。文档反映已核对的代码快照，不保证覆盖后续并行修改；旧测试报告不能直接证明新增启动策略已经通过。

核心方向是：共享专家定义，每个使用者拥有自己的运行实例、文件、记忆和会话状态；需要协作时，由文件所有者向指定账号分享只读快照。

## 当前结论

- 针对不同平台账号使用同一专家时的内容隔离，现有 UID、私有目录和访问控制设计覆盖了核心机制。当前优先验收这条链路，暂不增加 bubblewrap 叠加层。
- 当前方案并非完整的不可信代码沙箱：没有新增宿主文件树遮蔽、网络隔离或用户总资源配额。
- 隔离维度是 Octop `users.id`，不能直接等同于 MCN `company_id` 租户隔离，也不提供同一账号下不同专家之间的操作系统身份隔离。
- 本轮仅新增说明文档。业务机制结论属于静态确认；既有运行结果明确引用原报告，不作为本轮重新执行的结果。
